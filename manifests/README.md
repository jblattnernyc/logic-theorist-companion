# Manifests

This directory is reserved for project-level, cross-run, publication-bundle, or external-storage SHA-256 manifests and manifest-related documentation.

Manifests should identify the evidence bundle, creation command, file paths covered, and date of creation.

Ordinary per-run analysis manifests should live beside the analysis files they verify:

```text
reports/YYYYMMDD_HHMMSS/analysis_manifest.sha256
```
