# Baseline

This directory is reserved for baseline metadata captured before Logic Theorist execution or source modification.

Expected IPL-V baseline files may include:

```text
iplv_baseline_metadata.txt
iplv_git_head.txt
iplv_git_remote.txt
iplv_git_status_short.txt
environment.txt
```

The baseline must be captured from the local `IPL-V/` executable specimen after it exists and before running Logic Theorist.
