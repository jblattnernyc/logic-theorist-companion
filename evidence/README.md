# Evidence

This directory is reserved for organized evidence copies and evidence bundles.

Preserved evidence should be traceable to a source path, command, timestamp, source commit, and manifest. Large evidence bundles may later require an explicit storage policy.

General `.log` files are ignored elsewhere by default, but curated `.log` files under `evidence/` may be versioned when they are part of an organized evidence bundle with metadata and SHA-256 manifests.
